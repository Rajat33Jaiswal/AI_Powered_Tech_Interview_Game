# Interview.AI — React Frontend

This is the React frontend application for the AI-Powered Tech Interview Game (Interview.AI). It is built using **Vite**, **React**, and **Tailwind CSS v3**.

## 🛠️ Local Development

### 1. Configure Environment variables
Create a `.env` file in the client directory:
```ini
# Points to your local backend server
VITE_API_URL=http://localhost:5000
```

For production builds, set this to your hosted backend URL:
```ini
VITE_API_URL=https://your-backend-app.onrender.com
```

### 2. Commands
- Run development server:
  ```bash
  npm run dev
  ```
- Build production assets:
  ```bash
  npm run build
  ```
- Preview production build locally:
  ```bash
  npm run preview
  ```
